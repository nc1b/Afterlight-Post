# Afterlight Post

[Play in your browser or download for Windows on itch.io](https://nc1b.itch.io/afterlight-post)

## What it's about

Afterlight Post is a 2D puzzle game where you play as a mail carrier bringing light back to a dark harbor. Across ten streets, you guide shots around corners with mirrors, ring bells to charge the returning light, and use it to relight every lamp. We built it in Unity for Hack Club's Haven game jam around the theme **Bounce Back**.

## How to play

1. Press **Space** on the title screen, then choose **01 First Light** from the level select screen.
2. Walk into position with **WASD** and fire in any direction with the **arrow keys**. Every shot retraces its path. If it hits a bell, the returning shot lights any lamps it passes.
3. Use mirrors to turn shots around corners. Striped mirrors flip when a shot comes back past them, so a missed shot can set up the next one. Lighting a lamp opens its matching gate.
4. Light every lamp before you run out of shots, then press **Space** to move on. Use **Z** to recover your last shot or **R** to reset the street.

Look for scraps of mail and marks on the ground. They hint at how to open hidden mailboxes. A full walkthrough is also available from the itch.io page.

### Controls

| Key | Action |
| --- | --- |
| **W / A / S / D** | Move up, left, down, or right |
| **↑ / ← / ↓ / →** | Fire in that direction |
| **Z** or **Backspace** | Undo the last shot and recover its charge |
| **R** | Restart the current street |
| **Space** or **Enter** | Confirm, close a letter, or advance after clearing a street |
| **Esc** | Go back, or quit from the title screen |
| **M** | Toggle sound |
| **F11** | Toggle fullscreen |

## Run it on Windows or in Unity

For Windows, download `Afterlight-Post-Windows.zip` from itch.io, extract the entire ZIP, and open `Afterlight Post.exe`.

To run the source, open the repository folder in **Unity 6000.6.9f1**, open `Assets/Scenes/Main.unity`, and press **Play**.
